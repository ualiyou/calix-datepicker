# Geometric Calix Mark

## Goal

Replace the calendar-shaped Calix mark with a more distinctive minimal symbol.

## Design

- Draw an open, geometric `C` as an inline SVG using a rounded stroke.
- Put one violet circular accent in the open space, suggesting a selected date
  without using a generic calendar icon.
- Retain the `Calix` wordmark and existing accessible brand-link label.
- Keep the mark at its current 2.8rem display size; do not change navigation
  layout or any other landing content.

- Confirm the homepage remains reachable from the active local development server.
