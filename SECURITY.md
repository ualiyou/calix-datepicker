# Security Policy

## Supported Versions

Calix is pre-1.0. Security fixes are applied to the latest published minor release.

| Version | Supported |
| ------- | --------- |
| latest  | ✅        |
| < latest | ❌       |

## Reporting a Vulnerability

Please **do not** open a public issue for security vulnerabilities.

Instead, report privately via GitHub's
[private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability)
on this repository, or email **security@calix.dev**.

We aim to acknowledge reports within 72 hours and provide a remediation timeline
after triage. Once a fix is released, we will credit reporters who wish to be
acknowledged.
