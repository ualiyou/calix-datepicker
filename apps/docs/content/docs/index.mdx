**Calix** is a React date picker whose calendar rules are independent of its UI.
It stores the selection as ordinary JavaScript `Date` values at the public API,
while adapters handle calendar-specific arithmetic, names, parsing, and layout.

That separation lets the same component render Gregorian or Jalali dates without
a second picker, duplicated styling, or locale-specific UI branches.

## What you get

- **Selection:** single, multiple, range, week, month, quarter, and year modes.
- **Calendars:** bundled Gregorian and Jalali adapters; custom adapters are supported.
- **Rendering choices:** `DatePicker` for a popover, `Calendar` for inline use,
  or hooks and compound components for complete DOM control.
- **Constraints:** min/max dates, allow/deny lists, weekdays, months, years,
  holidays, business days, and a custom disabled-date predicate.
- **Localization:** BCP-47 locales, RTL, localized digits, labels, and configurable week starts.
- **Styling:** no required CSS framework; semantic classes, `data-*` state, and optional themes.
- **Accessibility:** keyboard navigation, roving focus, ARIA grid semantics, and focus restoration.

## Choose an entry point

| Need                                  | Start with                                                      |
| ------------------------------------- | --------------------------------------------------------------- |
| A standard trigger and popup calendar | [`<DatePicker>`](/docs/getting-started)                         |
| An always-visible calendar            | [`<Calendar>`](/docs/getting-started#an-inline-calendar)        |
| Custom popup layout or trigger        | [Compound `DatePicker` parts](/docs/hooks#compound-date-picker) |
| Your own calendar markup              | [`useCalendar`](/docs/hooks#usecalendar)                        |
| A date text field                     | [`useDateInput`](/docs/hooks#usedateinput)                      |
| A standalone clock-time field         | [`TimeField`](/docs/picker-modes#time)                          |

## Packages

| Package                     | Purpose                                                                        |
| --------------------------- | ------------------------------------------------------------------------------ |
| `@alydev/datepicker`        | React components, hooks, and public value helpers.                             |
| `@alydev/core`              | Calendar contracts, selection strategies, validation, parsing, and formatting. |
| `@alydev/adapter-gregorian` | Gregorian adapter, backed by `date-fns`.                                       |
| `@alydev/adapter-jalali`    | Jalali/Persian adapter, backed by `date-fns-jalali`.                           |
| `@alydev/holidays-iran`     | Maintained Iranian public-holiday data for Jalali years 1400–1420.             |
| `@alydev/holidays-international` | New Year's Day and Christmas Day data for 2000–2100.                      |
| `@alydev/themes`            | Optional default and minimal CSS themes.                                       |
| `@alydev/icons`             | Tree-shakeable SVG icons.                                                      |
