---

Install the React binding and at least one calendar adapter. Add the optional
theme package for default styling.

<Tabs items={["pnpm", "npm", "yarn"]}>

```bash tab="pnpm"
pnpm add @calix/react @calix/adapter-gregorian @calix/themes
```

```bash tab="npm"
npm install @calix/react @calix/adapter-gregorian @calix/themes
```

```bash tab="yarn"
yarn add @calix/react @calix/adapter-gregorian @calix/themes
```

</Tabs>

Need the Persian calendar too?

```bash
pnpm add @calix/adapter-jalali
```

## Peer dependencies

`@calix/react` expects **React 18.3+ or 19** (`react` and `react-dom`). The
Gregorian adapter depends on `date-fns`; the Jalali adapter on `date-fns-jalali`.
These are pulled in automatically.

## Import the theme (optional)

```ts
import "@calix/themes/default.css"; // full theme
// or
import "@calix/themes/minimal.css"; // structural only
```

The library works completely unstyled too — see the [Theming guide](/docs/theming).
