Choose a configuration and see it immediately. The code tab always contains
the final, dependency-ready component for the current setup.

For fixed international observances, select **International** under Holiday data,
or pass the dataset directly:

```tsx
import { internationalHolidays } from "@alydev/holidays-international";

<Calendar holidayData={internationalHolidays} showHolidays />;
```
