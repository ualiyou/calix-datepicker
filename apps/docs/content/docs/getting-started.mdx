## A single-date popup

The `DatePicker` component owns the trigger, popover positioning, calendar, and
focus behavior. Pass an adapter and, when parent state needs the value, use
`value` with `onChange`.

```tsx
"use client";

import { useState } from "react";
import { DatePicker } from "@alydev/datepicker";
import { gregorian } from "@alydev/adapter-gregorian";
import "@alydev/themes/default.css";

export function Example() {
  const [value, setValue] = useState<Date | null>(null);

  return (
    <DatePicker
      adapter={gregorian}
      locale="en-US"
      value={value}
      onChange={setValue}
      placeholder="Choose a date"
      theme="light"
    />
  );
}
```

## An inline calendar

Use `Calendar` when the calendar should always be visible. It shares the same
selection, localization, and constraint props as `DatePicker`.

```tsx
import { Calendar } from "@alydev/datepicker";
import { gregorian } from "@alydev/adapter-gregorian";

<Calendar adapter={gregorian} locale="en-US" showToday showClear />;
```

## Controlled and uncontrolled values

Use `value` and `onChange` when the parent owns the selection. Use
`defaultValue` when Calix should retain it internally. `onChange` is called in
both cases.

```tsx
// Calix owns the value after the initial render.
<Calendar adapter={gregorian} defaultValue={new Date()} onChange={console.log} />
```

The public value is always JavaScript `Date` data:

| Mode                                        | Value                                        |
| ------------------------------------------- | -------------------------------------------- |
| `single`                                    | `Date \| null`                               |
| `multiple`                                  | `Date[]`                                     |
| `range`, `week`, `month`, `quarter`, `year` | `{ start: Date \| null; end: Date \| null }` |

## Switch calendars

The adapter controls date math; `locale` controls language, digits, and direction.
Switch to Jalali by replacing the adapter:

```tsx
import { jalali } from "@alydev/adapter-jalali";

<DatePicker adapter={jalali} locale="fa-IR" dir="rtl" placeholder="تاریخ را انتخاب کنید" />;
```

`dir` is derived from the locale when omitted, so it is normally not necessary
to set it yourself.

## Serialize output for a form or API

Keep `onChange` for typed values. Add `onOutputChange` when you also need a
formatted string or JSON payload:

```tsx
<DatePicker
  adapter={gregorian}
  outputPattern="yyyy-MM-dd"
  onOutputChange={(value) => console.log(value)}
/>
```

Set `outputFormat="json"` for JSON instead of text. Next, see
[Picker modes](/docs/picker-modes), [Localization](/docs/localization), or
[Hooks](/docs/hooks).
